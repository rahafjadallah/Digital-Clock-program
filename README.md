## 📌 About The Project

Digital Clock is a simple and interactive web application built using HTML, CSS, and JavaScript. It displays the current local time in a 12-hour format with AM/PM indicators. The clock automatically updates every second to show the accurate current time.

## ✨ Features

- Display the current local time.
- Use the 12-hour time format.
- Show hours, minutes, and seconds.
- Display AM/PM indicators.
- Automatically update the clock every second.
- Add leading zeros to single-digit hours, minutes, and seconds.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. The digital clock will automatically display the current time.
5. The clock updates every second.
